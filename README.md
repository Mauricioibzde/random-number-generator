# Random Number Generator

Description
- Simple frontend project that generates random numbers via a web interface.
- Main files: `index.html` and scripts in `assets/script/script.js`.

Features
- Generates random numbers.
- Responsive UI with styles located in the `style/` directory.

Usage (local)
1. Open the `index.html` file in your browser (double-click or use "Open with").
2. The interface will load and you can generate random numbers.

Project Structure

| Icon | Item | Description |
|---:|---|---|
| 📄 | `index.html` | Main page. |
| 🗂️ | `assets/` | Project assets directory. |
| 🖼️ | `assets/icon/` | Icons used by the UI. |
| ⚙️ | `assets/script/script.js` | JavaScript with the random number generation logic. |
| 🎨 | `style/` | CSS files: `global.css`, `hero.css`, `index.css`, `mobile.css`, `nav.css`, `uttilitys.css`. |

Edit and Test
- To change behavior, edit `assets/script/script.js`.
- To change visuals, edit the files in `style/`.
- Reload `index.html` in the browser to see your changes.
